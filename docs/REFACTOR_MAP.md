## כללי פירוק

1. **העבר, אל תשנה.** הקוד עובר כמו שהוא. תיקונים ושיפורים — רק בצעד הבא.
2. **קלט מפורש.** הפונקציה החדשה מקבלת את מה שהיא צריכה כפרמטרים (`ctx`, `originX/Y`, מצב, תמונות). בלי משתנים גלובליים חבויים.
3. **לוגיקה ל-`src/game/`, ציור ל-`src/render/`.** לוגיקה טהורה מקבלת בדיקה (`*.test.ts`).
4. **אותו דבר בדיוק:** `tsc` + כל הבדיקות + `vite build` + צילום מסך לפני/אחרי באותו `?spawn=`.
5. **commit נפרד לפירוק** ("Extract DJ set from IsoArenaCanvas (no behavior change)"), ורק אחריו השינוי האמיתי.
6. **מעדכנים את הטבלה הזו** (סטטוס ✅ + שם הקובץ החדש).
